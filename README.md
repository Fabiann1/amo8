# IMAS · CRM менеджера

Рабочее место менеджера в стиле amoCRM на **FastAPI**: сделки (воронка), чаты, задачи, рабочий стол.

ИИ, промпты, вебхук amoCRM, классификация клиентов и автоответы живут в **n8n** (воркфлоу
«AI Automation + amoCRM»). Сайт ИИ не вызывает: он показывает то, что n8n записал в amoCRM, и выполняет
действия менеджера.

## Запуск

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python run.py
```

или двойной клик по `start.bat` (он сам установит зависимости). Откройте http://localhost:8080,
документация API — http://localhost:8080/docs.

1. При первом входе придумайте пароль.
2. Сайт откроется в **демо-режиме** с тестовыми сделками, чтобы можно было освоиться.
3. **Настройки → Подключение amoCRM**: переключите на «Мой аккаунт amoCRM», укажите адрес аккаунта и
   долгосрочный токен, нажмите «Проверить подключение».
4. **Настройки → Отправка и теги**: поле «AI ответ» и ID Salesbot — те же, что `reply_field_id` и
   `salesbot_id` в узле CRM Config в n8n. Там же можно указать ссылку на форму «Manager console» в n8n,
   тогда в чате появится кнопка «ИИ-помощник (n8n)».

Порт задаётся переменной `PORT`. Настройки и сессии хранятся в `data/` — не публикуйте эту папку, там токен amoCRM.

## Как сайт работает вместе с n8n

| Что видит менеджер | Откуда данные |
|---|---|
| Переписка в чате и карточке сделки | примечания `[CLIENT]`, `[BOT]`, `[MANAGER]`, которые пишет n8n |
| Оценка клиента (статус, температура, балл, резюме) | последнее примечание `[AI-STATE]` |
| Черновики ИИ с кнопкой «Использовать черновик» | примечания `[AI DRAFT]` |
| Режим ИИ: Авто / Подсказки / Выкл. | теги `AI_STOP` и `AI_DRAFT` на сделке |

Действия менеджера на сайте повторяют консоль менеджера из n8n (без ИИ):

- **Отправить** — примечание `[MANAGER]` → текст в поле «AI ответ» → запуск Salesbot. n8n видит
  `[MANAGER]` и переводит ИИ в режим подсказок, а своё эхо-сообщение игнорирует.
- **Режим ИИ** — ставит или снимает теги `AI_STOP`, `AI_DRAFT`, `AI: нужен менеджер` и пишет `[AI-CONTROL]`.
- Этап, бюджет, ответственный, примечания и задачи меняются напрямую через amoCRM API.

## Структура

```
run.py                 запуск uvicorn
app/main.py            приложение FastAPI, обработка ошибок, статика
app/routers/           API: auth (вход), settings (настройки, amoCRM), crm (сделки, чаты, задачи)
app/services.py        работа с данными amoCRM
app/notes.py           чтение примечаний n8n
app/amocrm.py          асинхронный клиент amoCRM API v4 + демо-имитация
app/config.py, db.py   настройки (data/config.json) и SQLite (сессии, «прочитано»)
static/                интерфейс (HTML/CSS/JS, без сборки)
```
